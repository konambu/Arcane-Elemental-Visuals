# Workshop preview

`preview-kenshi-title.jpg` is the image used for the initial Workshop upload.
It was generated with AI using the Kenshi title-screen artwork and this mod's
effect preview as references. The result alters both the title artwork and the
effects and is not a gameplay screenshot.
